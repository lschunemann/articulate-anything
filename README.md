# Articulate Anything: Methods Overview

This repository provides methods for automatically modeling articulated objects via Vision-Language Foundation Models (VLFMs). Below are the main methods implemented in various modules:

---

### **Methods**

#### **1. 2D to 3D Reprojection**

**Module:** `articulate_anything/2d_to_3d.py`

**Usage:**

```bash
python articulate_anything/2d_to_3d.py drawer
```

**Input:** The name of the RLBench object.

**Expected Data Structure:**
```
datasets/
   output_views/
      drawer/
         camera_params_...       # Camera parameters
         depth_drawer_...        # Depth maps
         render_drawer_...       # Rendered drawer views
         drawer.glb              # Generated object mesh
   segmentation_masks/
      drawer/
         render_drawer_..._results.json  # Segmentation results
         render_drawer_..._vis.png       # Visual masks
```

**Description:**
- This method takes segmented views of a target object along with its mesh. 
- It reprojects segmentation masks into 3D point clouds. 
- Segmented part instances are grouped together if they overlap in 3D space.  
**Output:**  
- Visualizations of part meshes
- Segmented point clouds
- Meshes for each unique part

---

#### **2. Chamfer Distance Calculation**

**Module:** `articulate_anything/chamfer_comparison/calculate_chamfer.py`  
**Usage:**  
```bash
python calculate_chamfer.py --gt gt --methods Trellis hunyuan rodin --output-dir results
```

**Input:**  
1. Name of folder with ground truth meshes
2. Name of folders with meshes generated by methods to be compared  
3. Name of the output directory

**Description:**
- Aligns the two meshes.
- Calculates the Chamfer Distance between ground truth and generated meshes.

---

#### **3. Detect Articulated Parts**

**Module:** `articulate_anything/detect_articulated_parts.py`

**Description:**  
- Takes a video demonstration of the target object as input.
- Makes a Vision-Language Model (VLM) API call to detect individual object parts.  
**Output:**  
- A formatted string of detected parts directly usable for part segmentation with DINO/SAM APIs.

---

#### **4. Mesh Segmentation with DINO-X**

**Module:** `articulate_anything/mesh_seg_dino-x.py`

**Description:**  
- Takes a directory containing rendered views of the target object as input.  
- Calls the DINO-X API to output segmentation masks.  
**Output:**  
- Segmentation masks as `.png` and `.json` files.
